协作版数据迁移助手

把旧地址（服务器已挂的 fca9e…）浏览器里存的协作版数据，搬到这个永久新地址。
第一步 · 从旧地址导出（在你打开旧地址的那个浏览器里做）

1. 地址栏输入旧地址 https://fca9e04e129c47a0bb738c9a7d4cbf99.gz4.agentos-app.net（页面打不开、显示错误也没关系）。
2. 按 F12 打开开发者工具 → 点顶部 Application（应用） 标签 → 左侧展开 Storage → Local Storage → 点开那个 fca9e…agentos-app.net 的网址。
3. 右边列表中找到 dp_collab_cache，双击它的「值」那一栏，Ctrl+A 全选，Ctrl+C 复制。
4. 回到本页面，粘贴到下方第一个框。
5. 同样找 dp_collab_aicfg（如果有），复制粘贴到第二个框（没有就留空）。
找不到旧地址的 Local Storage？备选方案

如果 Application 面板里看不到 fca9e 那一项，说明这台电脑没存过、或已被清空。可以改用保底地址 https://98668796b10a49fcb710cb53d4c2f071.sh1.agentos-app.net（同样步骤，但它停更在 8 月初，数据可能不全）。或者把 fca9e 那台电脑的浏览器数据导出来。
